# Sbei Hydraulics

Official website repository for **Sbei Hydraulics**, hosted on GitHub Pages with custom domain support (`sbei-hydraulics.com`).

## Overview

This repository contains the web source files for Sbei Hydraulics. Changes pushed to the `main` branch automatically trigger a GitHub Pages build and deployment to publish updates to the live site.

## Live Website

- **Custom Domain:** [https://sbei-hydraulics.com](https://sbei-hydraulics.com)
- **GitHub Pages URL:** [https://omarsbei.github.io/Sbei-Hydraulics/](https://omarsbei.github.io/Sbei-Hydraulics/)
